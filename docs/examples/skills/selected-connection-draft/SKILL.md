# 在指定连接中整理草稿

本示例是指导内容，不是可执行程序，不会安装服务、读取凭据或修改授权。

## 使用前提

- 用户必须明确选择本次使用的连接别名，例如“个人笔记”或“工作笔记”。别名有重复、缺失或同时存在多个候选时，先请用户明确选择，不猜测账户。
- 在当前工具目录中确认该连接拥有已授权的文档列表/搜索与创建草稿能力。验收夹具的原名分别为 `list_documents`、`search_documents`、`create_draft`；实际调用使用宿主提供的完整模型工具名称，不自行拼接或借用其他连接的同名工具。
- 缺连接或缺工具授权时，说明缺少哪项，并让用户在“扩展 → 已连接服务”配置。不能自动添加连接、授权工具、访问控制端点，或通过终端/浏览器绕过工具停用。

## 流程

1. 复述用户所选连接别名、检索主题和草稿目标。目标含混时先澄清；此说明不替代宿主权限检查。
2. 只使用所选连接内已有授权的列表/搜索工具，找到相关文档。不混合其他账户的数据。
3. 根据文档整理草稿正文，调用该连接的已授权创建草稿工具。已授权工具在当前任务入口允许时自动执行，不添加“每次写入均有确认弹窗”的承诺，也不把一次授权视为全服务授权。
4. 报告实际返回的草稿 ID、所属连接和执行状态。没有 ID 或确认结果时不宣称已创建。
5. 若授权撤销、连接停用或工具定义变化需复核，停止对应调用并提示用户检查授权。不要切换到其他连接继续写入。
6. 创建后发生超时、断网或不确定错误时，不自动重放创建操作。先通过已授权的只读检索核对；结果仍不明确则明确报告“不确定”，请求用户核查。

后台入口仍服从宿主入口策略。本示例不授予后台执行权限，不声称撤销、取消或停用可以回滚远端操作。
