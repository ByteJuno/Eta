## 验证中修复

- 日历协调器测试的泛型回调只抛异常时无法推断类型：显式指定结果类型。
- MCP 旧协议调用 404 测试原先要求自动重放工具调用；更新为一次调用并返回异常，保留只读目录发现的原重连测试。
- 日历审批与 MCP 目标选择 Compose 界面改用 `currentStateAsState()` 订阅生命周期；保留事件回调中的即时检查。
- 日历预览测试按解析后的 JSON 校验时区，避免将合法 `\/` 转义误判为字段丢失。
- 文件导入测试用 Path 前缀比较替代硬编码 `/`；要求 Android/POSIX 绝对路径的旧测试在 Windows 显式跳过，不放宽生产路径校验。该跳过仍需在 POSIX 环境执行。
