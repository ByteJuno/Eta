# Eta 3.3.1-beta.1

基于上游 3.3.0，版本码 `2026101001`。

## 更新内容

- 支持执行中实时插话。聊天输入框和浮层都可调整当前任务；正在生成的模型请求会被中断，已开始的工具完成后重新规划，尚未开始的动作跳过。
- 侧边栏新增通知中心。模型和后台复盘提出的现实记忆、技能方案经过用户同意才会应用，支持详情、拒绝和继续完善；继续完善打开带方案草稿的新会话。
- 角色库新增默认助手系统提示词编辑、保存和恢复默认。提供商已有自定义提示词优先，角色会话继续使用角色卡。
- 合并上游 3.3.0，补齐本分支数据库迁移，保留已有会话、模型绑定和自动任务数据。
- 补回请求耗时与平均输出速度统计、自动任务调度的并发保护，兼容早期贡献分支的数据库升级。
- Beta 发布标签会标记为预发布，保留稳定版 Latest。

## 验证

完整单元测试 1768 项，零失败、零错误，2 项跳过；Android Lint 零错误。
vivo V2419A / Android 16 / OriginOS / KernelSU + LSPosed 上完成停止续聊、实时插话、通知审批、提示词编辑、浮窗及 GUI 回归。Release APK 使用本仓库既有发布证书，经过 R8 构建和签名校验；实机功能检查使用 Debug 包。

测试页面的 6 次有效点击，工具调用从 18 次降到 6 次，工具累计耗时从 4886ms 降到 3916ms。这是同机单次合成场景测量，不包含模型和网络耗时。详见 [GUI 审计](AGENT_GUI_AUDIT_3.3.1.md) 和 [验证记录与截图](VALIDATION_3.3.1_BETA.md)。
